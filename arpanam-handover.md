# Arpanam — Project Handover

## What is Arpanam
A personal financial allocation tracker PWA. The name is Sanskrit for "offering/dedication". The user sets aside a portion of salary across self-defined buckets (categories) representing purposeful giving — family, service, devotional spending etc. Built as a mobile-first PWA hosted on GitHub Pages.

## Architecture

### Data model (localStorage key: `arpanam_data`)
```json
{
  "meta": { "lastUpdated": "ISO string", "version": 1 },
  "settings": { "triggerDay": 1, "pinHash": null },
  "categories": [
    { "id": "uuid", "name": "string", "emoji": "string", "order": 0, "monthlyAmount": 0, "createdAt": "ISO string" }
  ],
  "transactions": [
    { "id": "uuid", "categoryId": "uuid", "type": "credit|debit", "amount": 0, "note": "string", "date": "ISO string", "createdAt": "ISO string", "auto": false }
  ]
}
```

### Key principles
- **Offline first** — localStorage is primary, Firestore is optional mirror
- **Balances are never stored** — always computed from transactions
- **Last-write-wins** via `meta.lastUpdated` for cloud sync conflict resolution
- **No default categories** — user sets up from scratch
- `auto: true` on transactions means generated by the app (auto-credit or period entry)

## Core Features (all built)
1. **PIN protection** — 6-digit, SHA-256 hashed, 5 attempt lockout, 30s cooldown
2. **Categories (buckets)** — add/edit/delete, emoji picker, monthly credit amount
3. **Auto-credit trigger** — runs on app open on/after trigger day (1st or 2nd of month), skips if already credited that month, shows banner on home screen when credits added
4. **Per-category features:**
   - Opening balance (credit or debit)
   - Add Period — historical credit/debit entry for a date range, shows existing periods
   - Record Spend — manual debit entry
   - Edit/delete individual transactions
   - Clear all transactions for a category
   - Transaction list with All/Credit/Debit filter and Newest/Oldest sort
   - Summary row — total in, total out, transaction count
5. **Bulk Period Entry** (Settings) — add credit/debit history across all categories at once, same or different amounts/notes per category, undo support
6. **Export/Import** — JSON backup, last-write-wins on import, force import option if backup is older
7. **Cloud sync** — optional Google Auth, auto-push on every data change, auto-pull on sign in, sign out (keeps cloud data), delete cloud data (separate destructive action)
8. **PWA** — installable, Telugu అ gold coin icon, offline capable
9. **SW + clear cache** — update detection banner, clear cache button in home footer

## Decisions Made (don't revisit without good reason)
- Salary-split model rejected — per-bucket monthly amount is the right model
- No default categories — user sets up from scratch
- Export/import kept even with Firestore — offline backup is non-negotiable
- PIN kept even with Google Auth — protects from accidental access by family (kid)
- Last-write-wins (not merge) for sync — single primary device usage, acceptable tradeoff
- Offline writes allowed — user disciplines themselves to sync before writing on second device
- Embedded emoji picker — keyboard emoji rejected as poor UX
- SW + clear cache button together — SW detects update, clear cache button triggers immediate reload
- Telugu అ on gold coin icon — generated at build time using system fonts installed in GitHub Actions runner
